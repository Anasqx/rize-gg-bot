# Rize.gg — عجلة المكافآت

بوت مكافآت عربي بالأزرار، مع لفلات من الشات والفويس. البحث عن فريق متوقف في هذه النسخة؛ ملف التشغيل يشغّل المكافآت فقط.

## التشغيل

Node.js 24.17 أو أحدث. انسخ `.env.example` إلى `.env` واملأ التوكن ومعرّف السيرفر وروم اللوحة، ثم `npm ci` و`npm start`. لا ترفع `.env` أو قاعدة البيانات إلى GitHub. على Ryft أبقِ مجلد `data` محفوظًا وخذ نسخة احتياطية قبل نقل الاستضافة.

البوت ينشر اللوحة تلقائيًا ويسترجعها بعد إعادة التشغيل. لا يحتاج معرّف رسالة. يحتاج عرض الروم وإرسال الرسائل وتضمين الروابط وإرفاق الملفات وقراءة سجل الرسائل. لا يحتاج صلاحية Administrator أو Message Content أو Presence Intent.

## اختيار الرتبة

من اللوحة: **إعدادات الإدارة → اختر رتبة المشاركة**. يلزم Manage Server لفتح الإدارة. تبقى اللفات مقفلة حتى اختيار رتبة، ويتم التحقق من عضوية الرتبة عند كل لفة. بديلًا يمكن تعيين `REWARDS_ROLE_ID` قبل التشغيل الأول. لا تختَر رتبة الجميع.

## اللفلات

- الشات: ١٥ خبرة، مرة كل دقيقة لكل عضو. لا تُقرأ محتويات الرسائل.
- الفويس: ١٠ خبرة في الدقيقة، بعد تأهل العضو لدقيقة كاملة. يلزم عضوان بشريان بدون ميوت أو ديفن وخارج AFK؛ تغيير الحالة يعيد مدة التأهل.
- الحد المشترك: ٦٠٠ خبرة يوميًا بتوقيت السعودية.
- تكلفة اللفل التالي: ١٠٠ + ٥٠ × اللفل الحالي.
- كل خمسة لفلات جديدة تمنح تذكرة واحدة. كل لفة تستهلك تذكرة واحدة.
- أرصدة التجربة القديمة لا تتحول إلى تذاكر فعلية. الإدارة تستطيع منح تذكرة مع تسجيل العملية.

إجمالي النقد ٠٫١٪؛ لا يضمن الفوز بعد عدد محدد من اللفات. اختيار النتيجة عبر مولّد عشوائي آمن، ثم عرض GIF يطابق النتيجة. الخانات متساوية لتظهر كل الجوائز بوضوح؛ حجم الخانة لا يمثل نسبة الفوز. قائمة الجوائز تعرض أسماء الجوائز فقط؛ الأوزان الفعلية محفوظة في الكود والجدول أعلاه.

الجوائز النقدية متاحة دائمًا بدون سقف شهري، ولا تتحول إلى ميزة أخرى مهما بلغ إجمالي الجوائز. تبقى المطالبات محفوظة للاستلام من الإدارة، ونسب الفوز المذكورة ثابتة.

**الميزات دائمة وتُفعّل يدويًا من الإدارة.** لا تنتهي المطالبة بانتهاء مدة، ولا ينفذ البوت تحويلات نقدية أو يمنح صلاحيات صوتية تلقائيًا. يعرض سجل الجوائز رقم المطالبة، ويمكن للإدارة تسجيل تسليمها. صلاحية Discord الخاصة بالسحب تشمل الدسكونيكت أيضًا؛ منح صلاحيات عبر رتب يحتاج إعداد رتب مناسب في السيرفر. يمكن تكرار الفوز بالميزة نفسها؛ لا توجد إعادة سحب أو تعويض تلقائي.

## التحقق

`npm test` يتضمن اختبارات النسب الدقيقة، التذاكر، منع تكرار الصرف، شرط الرتبة، استمرار الجوائز النقدية بدون سقف، حد الخبرة وصلاحيات الإدارة. ملفات LFG القديمة محفوظة للتوافق مع البيانات والاختبارات ولا تعمل عند تشغيل البوت.
